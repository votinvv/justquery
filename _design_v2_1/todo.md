2. Найди и устрани утечки светлой палитры в тёмной теме: grep по `Color32::WHITE`,

   в Scan (Disable / Rescan now) залиты белым — должны быть `p().field_bg` + 1px

3. `on_accent` теперь кремовый — проверь, что primary/destructive кнопки читают токен,
   а не белый литерал.

Приёмка: в тёмной теме три уровня поверхности различимы (panel < остров, поле темнее
panel); текст матовый, без чисто-белого; рамка ошибки (danger) визуально отличается от
рамки фокуса (коралл) на одном экране.

## Фаза 2 — Законы вёрстки (ритм форм, gutter, клип)
1. `widgets.rs`: хелпер `form_row(ui, label, |ui| контрол)` — label `Small`/`text_dim`,
   4px до контрола, 14px после ряда. Переведи на него все формы: Connect, Scan,
   поиск в Metadata-доке. Ручные label+field удалить.
2. Закон нижнего gutter: контейнер рабочей области резервирует 8px над статус-баром при
   любом размере окна; острова (редактор, грид, доки) не могут касаться бара. Проверь
   на маленьком окне с открытыми результатами — раньше грид въезжал в бар.
3. Закон скруглённого контента: у каждого скроллируемого острова паддинг ≥6px и клип по
   rounded rect (activity log сейчас режет первую строку по рамке). Редактору — верхний
   паддинг 4px (первая строка кода не липнет к рамке).
4. Статус-бар, мелочи: убрать висячий «|» после левой группы; resize-grip отодвинуть от
   чипа версии на 6px.

Приёмка: подписи в Connect визуально принадлежат своим полям; ни один остров не
касается статус-бара ни при каком ресайзе; лог/код не липнут к рамкам.

## Фаза 5 — Статус-бар
1. Чипы через `theme::tint`: bg = `tint(p().panel, цвет, 0.16)`, текст — цвет. Никаких
   светлых заливок в тёмной теме (сейчас SCAN-чип светлый — баг).
2. Надпись чипа — строчными: `scan` (и состояния `scan`/`idle`/`off` тоже строчными).
3. `postgres@host` — `p().ok` при активном соединении, `p().text_dim` без него.

Приёмка: тёмная тема — чип тёмно-зелёного тона со спокойным зелёным текстом;
identity зелёный только при коннекте; всё строчными.

## Фаза 6 — Тумблер подключения + Disconnect-модалка + пустой экран
1. Тулбар: вместо пары connect/disconnect — одна кнопка-тумблер. Глиф `plug` (пока из
   lucide-аналога, после фазы 8 — свой): отключены → `text_dim`, tooltip «Connect…»,
   клик открывает Connect; подключены → `p().ok`, tooltip «Disconnect», клик открывает
   модалку подтверждения.
2. Модалка Disconnect: «Disconnect from {user}@{host}?», кнопки Cancel +
   Disconnect (destructive primary: заливка `danger`, текст `on_accent`, геометрия
   primary). Enter = Disconnect, Esc = Cancel.
3. Пустой редактор: убрать подсказку «Connect Database → Connect»; одна строка
   «Ctrl+N — new query» по центру, `text_dim`, видна только когда нет вкладок.

Приёмка: одна кнопка живёт в обоих состояниях и перекрашивается; дизконнект всегда
через подтверждение; на пустом экране одна честная подсказка, после открытия вкладки
исчезает.
